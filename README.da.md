# AI RAM Guard

Se, hvor meget RAM Claude, Codex og Cursor bruger, og ryd op i efterladte hjælpere. Gratis og open source.

## Download

- **[Windows](https://github.com/byensitmagnus/ai-ram-guard/releases/latest/download/AiRamGuard-Setup.exe)** — Åbn filen, og klik **Install**. Kræver Windows 10/11, 64-bit.
- **[Mac — beta](https://github.com/byensitmagnus/ai-ram-guard/releases/latest/download/AiRamGuard-mac-universal.dmg)** — Åbn DMG-filen, træk appen til **Programmer**, og åbn den. Kræver macOS 13+. Virker på Apple Silicon og Intel.

Mac-betaen viser RAM- og diskforbrug og rydder op i efterladte hjælpere. Den har færre funktioner end Windows og kræver godkendelse ved første åbning. Windows kan vise SmartScreen. [Hjælp til første åbning](docs/install.md#first-open-approval).
