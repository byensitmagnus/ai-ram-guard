# Security policy

AI RAM Guard closes and trims processes, so we take safety bugs seriously, especially any case where it touches a process it shouldn't.

**Report privately** through [GitHub's private vulnerability reporting](https://github.com/byensitmagnus/ai-ram-guard/security/advisories/new). Please don't open a public issue for security problems.

We aim to answer within 7 days. Supported version: the latest release.
