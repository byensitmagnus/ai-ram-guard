# AI RAM Guard

See how much RAM Claude, Codex and Cursor use, and clean up leftover helpers. Free and open source.

## Download

- **[Windows](https://github.com/byensitmagnus/ai-ram-guard/releases/latest/download/AiRamGuard-Setup.exe)** — Open the file and click **Install**. Requires Windows 10/11, 64-bit.
- **[Mac — beta](https://github.com/byensitmagnus/ai-ram-guard/releases/latest/download/AiRamGuard-mac-universal.dmg)** — Open the DMG, drag the app to **Applications**, then open it. Requires macOS 13+. Supports Apple Silicon and Intel.

The Mac beta includes RAM monitoring, disk usage and leftover cleanup. It has fewer features than Windows and is not yet Apple-notarized. Windows may show SmartScreen. [First-open help](docs/install.md#first-open-approval).
