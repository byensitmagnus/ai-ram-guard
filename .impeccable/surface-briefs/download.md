# Download page

Scope: site/index.html. Mode: Operate; get a suitable installer and complete installation. This extends the existing app identity, not a replacement visual world. The user asked for a simpler GitHub page and download flow, and confirmed that scope.

## Direction contract

THESIS: a quiet download desk with the two operating systems visible immediately, followed by only the steps needed to open the app.

OWN-WORLD: inherit the app's dark neutral surfaces, magenta action, existing logo and readable system UI typography. Use spacing rather than feature cards.

STORY: see the purpose, choose Windows or Mac, download one file, and know what happens next. Technical documentation stays on GitHub.

FIRST VIEWPORT: compact identity header; a plain two-line heading and one sentence; Windows installer and Mac beta side by side with their requirements. A real Windows app screenshot follows the installation steps.

FORM: direct download page, a narrowly specified task from the user's request; seed: none (not applicable to a scoped extension).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
